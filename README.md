# 🐤 Flappy Bird Game (Python + Pygame)

A simple recreation of the classic **Flappy Bird** game built using **Python** and **Pygame**.  
The player controls a bird that must fly between sets of pipes without colliding. The game keeps track of the score and ends when the bird hits a pipe or falls off the screen.

---

## 🎮 Features
- Classic Flappy Bird mechanics (jump with space, X, or ↑ key).
- Randomly generated pipes with gaps.
- Score tracking (1 point per set of pipes passed).
- "Game Over" screen with score display.
- Smooth 60 FPS gameplay.

---

## 🛠️ Requirements
Make sure you have the following installed:
- Python 3.x
- Pygame library

Install pygame with:
```bash
pip install pygame
```

---

## ▶️ How to Play
1. Clone this repository:
   ```bash
   git clone https://github.com/Qazim-07/Flappy-Bird-Game.git
   ```
2. Navigate to the project folder:
   ```bash
   cd Flappy-Bird-Game
   ```
3. Run the game:
   ```bash
   python flappybird.py
   ```
4. Controls:
   - **Space / X / ↑ Arrow** → Make the bird jump
   - Avoid hitting pipes or falling down
   - Score increases as you pass through pipes

---

## 📂 Assets
The game uses the following image files:
- `flappybirdbg.png` → Background
- `flappybird.png` → Bird
- `toppipe.png` → Top pipe
- `bottompipe.png` → Bottom pipe

Make sure these files are in the same directory as the Python script.
